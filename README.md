# rCore Development Notes

Documentation for learning Rust through [rCore-Tutorial-v3](https://github.com/rcore-os/rCore-Tutorial-v3) — a RISC-V OS written in Rust.

## Background

Coming from xv6 (RISC-V + C), this repo captures notes, insights, and code analysis as I rebuild my OS knowledge in Rust.

## Topics

- Rust fundamentals learned through OS development
- Comparisons between xv6 (C) and rCore (Rust) design choices
- RISC-V privileged architecture and boot process
- Memory management, process scheduling, and file systems in Rust
